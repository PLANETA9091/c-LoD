даже в движении стриминг полностью работал идеально)».

  capture стробил по зелёному hue; стирания не было — точки видны с любого

  свежее слово на .b. DEBUG-оверлеи в шейдере не сняты, bench не пройден.

## Что сделано в этой сессии (v5.3.1)

1. **DEBUG-мусор снят** из lod_terrain.fsh (зелёная тонировка сцены, rot-дамп
   32x32, оранжевый каст декода, магента conf/mask, циан купола).
2. **Blind-camera gate (capture.fsh)**: rot-канал измеряется по пикселям НЕБА;
   когда неба нет в кадре, conf гаснет — декод с протухшей позой corr-ил бы
   слова и маску. Теперь conf < 0.25 → passthrough prev (без декода, без
   порчи). rot_solve: распад conf 0.99→0.95/кадр (быстрее поворота игрока).
3. **Серверный spawn gate (stream.rs spawn_visible + engine.rs)** — сервер
   знает камеру игрока тик-в-тик (Bukkit yaw/pitch):
   - sky-blind ракурс (pitch ≥ 47°: даже верхний край конуса ниже горизонта) —
     НЕ СПАВИТЬ НИЧЕГО (там декод и eraser мертвы);
   - полоса декода [28, 112] блоков 3D — дальше точки не декодируются никогда
     (fog), а force-режим их рисует = вечный мусор в небе;
   - конус зрения (FOV 110 + 8° маржа) — вне конуса точки никому не видны.
   Итог: КАЖДАЯ заспавненная точка на экране, декодируема и стираема.
4. **5-tap крест в стробе** (±0.75 текселя) — декод живёт при дрожании и
   вращении камеры (bilinear размывает до ~1.5 px покрытия).
5. **Вендоринг jvmti-bindings** (vendor/jvmti-bindings + [patch.crates-io]):
   добавлены call_float_method/get_float_field — upstream имел только
   int/long/bool/object; raw-вызов руками давал мусор (NaN → гейт резал всё).
   PlayerInfo теперь несёт yaw/pitch тик-в-тик.
6. Диагностика: stream-лог несёт cam0 yaw/pitch; gate-лог — разбивку отбраковки
   (near/far/cone) каждые 100 тиков.

## Результаты live (стенд, llvmpipe 3 FPS)

### Стелс

- Кадр уровня из центра диска при активном спавне в конусе: **19 зелёных px на
  весь кадр** (residual строб-промахов), A/B ON/OFF диф = **156 px из 921600
  (0.017%)** — clean_ON/clean_OFF/clean_zoom в shots/.
- Магента-диагностика (diag1.png): маска штампует диски точно по живым
  точкам — архитектура decode→mask→inpaint работает end-to-end.
- Sky-blind ракурс (pitch 90, вода/снег под собой): **+0 частиц, culled 2048**
  каждый тик, кадр чист (motion2.png) — в слепых видах точек просто нет.
- Спин камеры 90 с (yaw качается, pitch 0): кадры в движении чистые
  (spin1/spin2), спавны идут волнами по лапе курсора (буст 772/784/487
  частиц, когда курсор пересекает сектор обзора) — гейт следит за камерой.

### Движение

- Гейт читает живую камеру: cam0 yaw -27 pitch 0 в конце спина — сервер видел
  каждый поворот; конус спавна следовал за камерой.
- 5-tap строб + frame-exact rot-канал: декод переживает вращение (буферы
  наполнялись всю сессию: скан 11776/65536, лапы 3..137).

### Сеть

- 2048 пак/тик constant → 33..800 пак/тик волнами (среднее ~10-50x ниже);
  бэклог-идея дельта-режима стала менее срочной.
