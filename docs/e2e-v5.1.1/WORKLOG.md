## Починено в этом прогоне

1. **Десинк эффект-листа (v5.1.0 находка №7 → код-фикс).** `pe.add(Key)`
   может возвращать false бесконечно, пока цепочка УЖЕ на списке игрока —
   старый код спамил «add -> false» каждый тик (3954 строки за прогон) и
   не восстанавливался. Фикс: `sync_effect()` в engine.rs — при add-false
   раз в 100 тиков делает remove+add (проверенный ручной рецепт v5.1.0),
   лог только на успех/хилер. Прогон: ноль спама, 2 цепочки на игроке.

2. **renderClouds:false** в run_client.sh — дрейф облаков травил пиксельный
   диф тысячами ложных изменений (в первом A/B 5995 px почти целиком
   красные края облаков; после отключения облаков диф стал чистой
   фигурой силуэта).

3. **run_e2e_shots.sh: центр диска CX,CZ = 0,64** (синхрон с
   boot_server.sh center_x=0;center_z=64) + фолбэк счётчика cells из
   server.log (эндпойнт /clod-pack.info врёт cells=0/0 — косметика).

4. **Среда:** python-xlib (клик по пак-промпту) переустановлен; симлинк
   /home/z/tools/jdk25 → jdk-25.0.5+8 (boot_server.sh ждёт именно его).
