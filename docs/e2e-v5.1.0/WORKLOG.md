## Найдено и починено по ходу

1. **pitch в 26.3 tp инвертирован** (плюс = вниз; минус = вверх) — все старые
   «взгляды вниз» смотрели в небо. Проверено солнцем в зените.
2. **геймрул doDaylightCycle выпилен в 26.3** — день замораживается
   `time pause` (Paused clock minecraft:overworld); `time set 6000` работает.
3. **HTTP-бинд гонки при рестарте**: старый сервер держал 8199 ->
   "Address already in use" -> клиент не мог скачать пак. Лечится чистым
   ребутом (порт освобождается).
4. **Ключевой дефект капчера**: с низкой камеры (Y<100) частицы HI-плоскости
   (Y=120) проецируются НА ФОН НЕБА -> строб capture.fsh (dep<1e-6) их
   отвергает -> ВЫСОТЫ НЕ КАПЧУРЯТСЯ. Фикс-методика: капчер-двелл с ВЫСОКОЙ
   камеры (Y=150) глядя вниз — частицы на фоне земли, оба слова пишутся.
5. **Дальность рендера частиц ~90-110 блоков** (проба вбросов на 60/90/120):
   оболочка капчера живёт ВНУТРИ радиуса реальных чанков (128). Далёкие
   ячейки хайтфилда заполняются только когда игрок был рядом (персистентный
   ping-pong), поэтому LOD работает как «память» позади игрока + вейл.
6. llvmpipe-глитч мешей чанков при дальних tp (цветные колонны) — клиентский
   баг рендера, лечится рестартом клиента, не наш баг.
7. Спам "effect terrain add -> false" после релога клиента — рассинхрон
   st.terrain_on с состоянием игрока; лечится remove+add обоих эффектов.
