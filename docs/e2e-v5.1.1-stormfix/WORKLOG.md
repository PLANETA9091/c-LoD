## Главный баг сессии: шторм add->false (~11354 попыток за 8 минут)

**Симптом**: после быстрого релога клиента модуль спамил
`posteffect add -> false` ~100 раз/сек. Клиентская пост-цепочка получала
пакет эффекта на каждую попытку → рендер-тред клиента голодал → llvmpipe
фризился наглухо (два кадра подряд diff=0 на протяжении минут).

**Корень** (src/engine.rs, tier-переключатель): после релога per-player
состояние создаётся свежим (`terrain_on=false`), а серверная привязка
эффекта ПЕРЕЖИВАЕТ релог — 26.3 `PostEffectCommand.add` возвращает false,
если эффект уже привязан. Старый код делал `st.terrain_on = add_effect(...)`
→ false оставлял флаг выключенным → ретрай каждый тик, без конца.

**Фикс**: одно примирение remove+add при первом false, затем флаг = on до
следующего переключения тира (никаких ретрай-лупов). Симметрично для
remove->false (эффекта уже нет). Проверено живьём:

```
effect terrain resync (remove -> true) add -> true
effect atmosphere resync (remove -> true) add -> true
"add -> false" count за сессию: 0 (было 11354)
```

Клиент после фикса рендерит НЕПРЕРЫВНО (5/5 межкадровых diff != None на
протяжении минут) — фризы ушли.

## Прочие находки

1. **tp в креативе не держит высоту**: игрок после tp падает до земли/кроны
   (полёт не включён). Методика стенда: стеклянная платформа
   `fill X 149 Z X2 149 Z2 glass` + tp на неё — камера стабильно Y=150.
2. **Скан ограничен сгенерированными чанками**: клетки валидны только там,
   где есть чанки; стоянка игрока на месте даёт ~7-11k клеток (r≈91-121 от
   центра диска), дальше скан ждёт генерации (тикет-мост, не блокирующе).
3. **Чат на 1-2 FPS клиенте** считывается плохо (сообщение уходит за 10с,
   кадры редкие) — для координат locate надёжнее титры/actionbar.
4. Полигон диска задаётся `CLOD_CENTER="x,z" bash boot_server.sh`
   (скрипт теперь конфигурируемый; дефолт 0,64; v5.1.0-полигон: -930,796).
