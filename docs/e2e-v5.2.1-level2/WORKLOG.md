## Три бага стенда (найдены и устранены)

1. **Деплой не туда**: сервер грузит модуль из `~/mc-test/dist/modules/lod/`,
   а не из `~/mc-test/modules/lod/`. После копирования только в последний
   sha1 пака НЕ менялся (baf07239 — старый v5.2.0 шейдер!) — v5.2.1
   молча не попала в пак. Диагностика: `strings dist/modules/lod/liblod.so
   | grep -c nb2` (0 = старый) + сверка sha1 в server.log.
2. **tilde в консоли 26.3**: `execute as ... at @s run fill ~...` молча не
   работает; `say`/`list`/plain `fill X Y Z` работают. Башня: цикл
   `fill -932 Y 793 -926 Y 799 glass` + `tp Stepan -929.5 Y+1 796.5 0 90`.
   Креатив делает падения безопасными; double-tap пробела (полёт) на
   llvmpipe 1-2 FPS не срабатывает.
3. **Capture-буферы живут только через pitch-90 двелл**: sky-reject
   отсекает пыль на фоне неба, значит пыль капчурится ТОЛЬКО на фоне
   геометрии. Двелл вниз (весь экран = земля) копит clod_h_*/clod_c_*
   быстро; камера на горизонте буферы не наполняет. После КАЖДОГО
   рестарта сервера — минимум 12-20 мин pitch-90 двелла, потом
   горизонт-кадры. Симптом недостатка: краска только узкими рядами у
   заполненных секторов (diff ~2-9k px вместо ~100k).

Плюс подтверждено: doDaylightCycle false не держится — `time set 6000`
повторять перед каждым кадром (ночь гасит краску в diff: ночная краска
#7a7aff x0.24 на тёмном небе даёт diff < 15).

## Честная оговорка

Краска в этой сессии слабее v5.2.0-эталона (9.7k px против 112k): буферы
capture после рестарта ещё не покрыли весь диск. На реальном GPU
мерцания/медленности llvmpipe нет; буферная механика — свойство
потокового decode на софтверном рендере, не модуля. Сглаживание уровня 2
проверено валидацией GLSL + сборкой; полный живой A/B сглаживания
требует длинного двелла (>30 мин) или нескольких точек скана.
