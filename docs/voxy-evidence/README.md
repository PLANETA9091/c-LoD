## 1. Что Voxy реально рендерит (из шейдеров jar)

Пайплайн GL46 (`assets/voxy/shaders/lod/`):

1. **LOD = реальные блок-модели квадами**, НЕ хайтфилд. `lod/gl46/quads.frag` +
   `quads3.vert`: каждый квад несёт `uvec4 interData`:
   - `x` бит 0 = discardAlpha, биты 2–3 = tintingState (0/1-условный/2-принудительный),
     биты 4–6 = face, биты 8–11/12–15 = tileW/tileH (greedy-merge до 16×16),
     биты 16–31 = modelId (атлас 256×256 тайлов, каждый тайл 3×2 суб-грани).
   - 64-бит `QuadData` (`lod/quad_format.glsl`): pos 5+5+5 бит (секция 32³),
     size 4+4, face 3, **stateId 16 бит** (реальный блокстейт), **biomeId 9 бит**,
     **lightId 8 бит**.
2. **Текстуры**: `blockModelAtlas` сэмплится через `textureGrad(...)` (mip-цепочка) —
   зерно текстуры сохраняется на расстоянии (сглажено, но НЕ плоско).
3. **Свет**: `lod/lighting.glsl` — ванильная lightmap-текстура, UV из пакованного
   block/sky light (4+4 бита). Наша реконструкция lightmap(0,15) — корректна.
4. **Затенение граней**: в quads.frag НЕ применяется → запечено на Java-стороне
   генерации квадов (ванильные веса 1.0/0.8/0.6 — как у нас в color-модели).
5. **SSAO** (`post/ssao.comp`): offset 0.5 блока вдоль нормали, reproject,
   `ao = pow(dot,0.15)`, финал `clamp((1-ao)/3+2/3)` — затемнение НЕ глубже 2/3
   (33% максимум), деликатное. Есть `BETTER_SSAO` (Photon-VN, 12 шагов).
6. **Fog** (`post/blit_texture_depth_cutout.frag`, HAS_FOG):
   `fogLerp = clamp(length(pos)*endParams.x + endParams.y, 0, endParams.z)`,
   `rgb = mix(rgb, fogColour.rgb, fogLerp*fogColour.a)` — линейный, **3D-дистанция**,
   цвет = ванильный environmental fog. Наша модель fog совпадает.
7. **Глубина**: LOD-глубина переписывается в ванильный depth-буфер
   (`gl_FragDepth`) — правильная окклюзия с реальными чанками.
8. **TAA**: `taaShift()` в вершинном шейдере.

## 3. Сопоставление с c-LoD v5.2.2

| Механизм | Voxy | c-LoD | Статус |
|---|---|---|---|
| Lightmap | ванильная текстура | реконструкция texel(0,15) из fog | ✓ точно |
| Fog | линейный, 3D, ванильный цвет | тот же (NormalRenderPipeline.finish) | ✓ точно; бэнд кромки доработать |
| Face shade | 1.0/0.8/0.6 запечено | через height-градиент нормаль | ✓ |
| Палитра | блокстейты+biome tint | 6³ решётка + вода 216 | ✓ (это максимум dust-пути) |
| Зерно на расстоянии | mip текстуры | 2×2/крест усреднение цвета (25–30% identity остаётся) | ≈ приемлемо |
| AO | SSAO pass, cap 2/3 | нет | ✗ → добавить прокси по вогнутости |
| Вода | глубина+подводный рельеф | плоский ColWater | ✗ → градиент мель/глубь (рельеф дна dust-путь не передаёт — фиксировать как ограничение) |
| Подводный рельеф | да | нет данных (LO-байт = флаг 216) | ✗ безысходно для dust-пути (нужен протокол v2) |
| Текстуры | атлас | нет (dust-only) | ✗ по дизайну проекта |

## 4. Итерация v5.3 (evidence-backed, всё из п.1–2)

1. **AO-прокси**: вогнутость ячейки `hC - avg(hL,hR,hD,hU)` (соседи уже читаются
   для нормали — 0 доп. выборок) → затемнение с потолком Voxy `2/3`
   (`mix(1.0, aoCurve, 1/3)`).
2. **Вода**: доля водных соседей из уже существующего подсчёта в `color_at` →
   отмели (много сухопутных соседей) светлее и цианнее, открытая вода темнее
   (цель `#1c335d` при дневном lightmap).
3. **Бэнд кромки диска**: в зоне `fadeOut` дотягивать цвет к `fogTint`
   (= ванильный fog `#c0d7ff` днём) до 80% до смешения со сценой — белый бэнд
   как на ref2.
